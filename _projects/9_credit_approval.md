### Overview

Built a comprehensive set of machine learning models to predict credit approval outcomes, exploring both supervised and semi-supervised learning paradigms across classical and fuzzy classification techniques.

### Key Contributions

- **Multiple Model Architectures:** Implemented and compared Logistic Regression, Decision Trees, Support Vector Machines (SVM), and **fuzzy rule-based classifiers** for credit approval prediction.

- **Semi-Supervised Learning:** Explored semi-supervised approaches to leverage unlabeled data points, improving model generalization where labeled data was scarce.

- **Fuzzy Classifier Design:** Designed and tuned membership functions and fuzzy rules to capture human-like reasoning in credit decisions — particularly useful for borderline applicants.

- **Comparative Analysis:** Evaluated all models using metrics including accuracy, precision, recall, F1-score, and ROC-AUC, revealing trade-offs between interpretability and performance across classifier types.
