### Overview

Built a classification pipeline for automated histopathological grading of **Breast Invasive Ductal Carcinoma (IDC)** using classical and deep learning feature extraction techniques. This was part of a writing sample exploring both manual and automatic feature extraction strategies for cancer diagnosis.

### Key Contributions

- **Feature Extraction:** Combined **Fisher Vector** encoding (a classical hand-crafted statistical feature descriptor built on Gaussian Mixture Models) with a pretrained **ResNet-18** CNN backbone for deep feature extraction.

- **Classification Pipeline:** Designed a complete supervised classification pipeline covering preprocessing, feature extraction, dimensionality reduction, and multi-class grading.

- **Comparative Analysis:** Evaluated manual versus automatic feature extraction approaches, providing insights into accuracy-efficiency trade-offs for real-world histopathology applications.
