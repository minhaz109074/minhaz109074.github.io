### Overview

Maintained **StrataSpot**, one of AIT Inc's longest-running and most successful residential strata management projects, built on the **nopCommerce** architecture for Australian clients.

### Key Contributions

- **Bug Fixes & Improvements:** Debugged a complex legacy codebase, resolved production bugs, and implemented feature improvements with deployments on **Windows Server via IIS**.

- **Automated Uptime Utility:** Developed an automated IIS restart utility using a custom **Windows service (StrataSpot Cron Service)** to maximize server uptime and minimize manual intervention.

- **Performance Enhancement:** Implemented **in-memory caching** to significantly enhance site speed and responsiveness, reducing database load for frequently accessed data.

- **Event Management:** Developed a calendar-based event management system with automated **email notifications** (SmarterMail) for event participants and strata members.
