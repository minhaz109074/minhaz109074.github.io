### Overview

Contributed to **Caboodle Services**, an all-in-one sales enablement platform designed for natural product sales teams, integrating sales tracking, trade promotions, data analytics, and marketing tools.

### Key Contributions

- **Database Schema Design:** Designed and optimized database schemas to efficiently handle large-scale client sales data at production volumes.

- **Bulk Operations:** Implemented bulk data processing supporting CSV uploads ranging from **100 to 100,000+ records**, dramatically improving data entry efficiency for field sales teams.

- **Query Optimization:** Optimized complex PostgreSQL queries to improve system performance and responsiveness for data retrieval and dashboard rendering.

- **Reporting Engine:** Transformed unstructured sales data into structured formats to generate comprehensive reports and business insights for clients.

- **File Storage System:** Developed a robust file storage system enabling brands to manage files and folder structures for marketing assets.
